# Website Lists

Curated lists of websites and domains organized by category for OSINT reconnaissance.

<a id="contributing"></a>
## `> contributing`

Contribute lists of websites and domains in this format:

```
# Category Name - Description
# Brief context about the list

# ============================================
# SUBCATEGORY
# ============================================
example.com
anotherdomain.org
site.net
```

### Rules
- One domain per line, bare domain only (no `https://`, no trailing `/`)
- Use `#` comments for headers, subcategories, and notes
- Group related domains under subcategory headers
- Name files descriptively: `category-name.txt`

### Example

```
# Coffee Shops - National Chains
# US-based coffee chain websites

# ============================================
# MAJOR CHAINS
# ============================================
starbucks.com
dunkindonuts.com
peets.com
```
